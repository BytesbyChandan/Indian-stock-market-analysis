The notebooks folder contains Jupyter Notebook (.ipynb) files used for data processing, SQL analysis, and visualization in the Indian Stock Market Analysis project.

Key Activities:

Data Analysis: Retrieved and analyzed stock market data from MySQL using Python and Pandas.

SQL Integration: Executed SQL queries to analyze stock prices, daily returns, trading volumes, and sector performance.

Data Visualization: Created charts using Matplotlib and Seaborn to identify stock market trends.

Performance Comparison: Visualized stock performance, price movements, and sector-wise returns.

Insights Generation: Used analytical results and visualizations to understand historical stock market behavior.

Purpose: To maintain organized, reproducible Python notebooks that demonstrate the complete analytical workflow from SQL data retrieval to visual insights.
